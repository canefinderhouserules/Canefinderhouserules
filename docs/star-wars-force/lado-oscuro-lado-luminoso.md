# Lado Oscuro/Lado Luminoso

Basicamente se tiene una barra de karma. 0 es gris, neutral, -100 es full lado oscuro malvado, +100 es full lado luminoso buenito. Cada cierto punto se te dan ciertos beneficios.  
  
Los personajes jedi pueden empezar desde -20 hasta +20, donde prefieran ustedes.
