# Callback, Greater

**School** conjuration (teleportation); **Level** bard 5, druid 5, shaman 5, sorcerer/wizard 5, witch 5  
**Casting Time** 1 standard action  
**Components** V, S, M (a crushed grasshopper)  
**Range** 1 mile/level  
**Duration** 1 hour/level or until expended  
**Saving Throw** Fortitude negates; **Spell Resistance** yes (harmless)

This spell functions as callback, except as noted above.
