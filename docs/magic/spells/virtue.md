# Virtue

**School** transmutation; **Level** cleric 0, druid 0, inquisitor 0, medium 0, paladin 1, psychic 0, shaman 0, spiritualist 0  
**Casting Time** 1 standard action (1 AP)  
**Components** V, S, DF  
**Range** touch  
**Target** creature touched  
**Duration** 1 min.  
**Saving Throw** none; **Spell Resistance** yes (harmless)

With a touch, you infuse a creature with a tiny surge of life, granting the subject 1 temporary hit point.
