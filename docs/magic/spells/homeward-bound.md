# Homeward Bound

**School** abjuration; **Level** cleric 3, sorcerer/wizard 4  
**Casting Time** 1 minute  
**Components** V, S  
**Range** touch  
**Target** one willing extraplanar creature  
**Duration** instantaneous  
**Saving Throw** Will negates (harmless); **Spell Resistance** yes

This spell functions as *dismissal*, except that it affects only a willing extraplanar creature, whom it returns to its home plane.
