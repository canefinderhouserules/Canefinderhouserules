# Delay Poison, Communal

**School** conjuration (healing); **Level** alchemist 3, bard 3, cleric 3, druid 3, inquisitor 3, paladin 3, ranger 3, witch 3  
**Casting Time** 1 standard action  
**Components** V, S, DF  
**Range** touch  
**Target** creatures touched  
**Duration** 1 hour/level  
**Saving Throw** Fortitude negates (harmless); **Spell Resistance** yes (harmless)

This spell functions like [*delay poison*](delay-poison.md), except you divide the duration in 1-hour intervals among the creatures touched.
