# Minor Phantom Object

**School** illusion (figment) [mind-affecting]; **Level** sorcerer/wizard 4  
**Casting Time** 1 minute  
**Components** V, S  
**Range** 0 ft.  
**Effect** phantasmal, unattended, nonmagical object of nonliving plant matter, up to 1 cu. ft./level  
**Duration** 10 minutes/level (D)  
**Save** Will negates; **Spell Resistance** yes This spell functions as the *minor creation spell*, except the object created is a semi-real phantasm. Any creature that interacts with the object may make a Will save, with success causing the object to cease to exist. A gnome casting this spell may make a Spellcraft check in place of any Craft check required to make a complex item.
