# Inflict Pain, Mass

**School** enchantment [mind-affecting, pain]; **Level** antipaladin 4, inquisitor 5, medium 4, mesmerist 5, occultist 5, psychic 6, sorcerer/wizard 7, spiritualist 5, witch 7  
**Casting Time** 1 standard action  
**Components** V, S  
**Target** one creature/level, no two of which can be more than 30 ft. apart.  
**Duration** 1 round/level  
**Saving Throw** Will partial, see text; **Spell Resistance** yes

This spell functions like inflict pain except as noted above.
