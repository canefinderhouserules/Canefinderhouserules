# Invisibility, Greater

**School** illusion (glamer); **Level** bard 4, sorcerer/wizard 4  
**Casting Time** 1 standard action  
**Components** V, S  
**Range** personal or touch  
**Target** you or creature touched  
**Duration** 1 round/level (D)  
**Saving Throw** Will negates (harmless); **Spell Resistance** yes (harmless)

**Components**: V, S **Target** you or creature touched **Duration** 1 round/level (D) **Saving Throw** Will negates (harmless) This spell functions like *invisibility*, except that it doesn’t end if the subject attacks.
