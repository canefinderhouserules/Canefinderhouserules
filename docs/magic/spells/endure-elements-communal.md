# Endure Elements, Communal

**School** abjuration; **Level** alchemist 3, cleric 2, druid 2, paladin 2, ranger 2, sorcerer/wizard 2  
**Casting Time** 1 standard action  
**Components** V, S  
**Range** touch  
**Target** creatures touched  
**Duration** 24 hours  
**Saving Throw** Will negates (harmless); **Spell Resistance** yes (harmless)

This spell functions like endure elements, except you divide the duration in 1-hour increments among the creatures touched.
