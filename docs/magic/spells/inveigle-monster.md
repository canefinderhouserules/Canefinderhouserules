# Inveigle Monster

**School** enchantment (charm) [mind-affecting]; **Level** bard 5, mesmerist 5, psychic 6, sorcerer/wizard 7, witch 7  
**Casting Time** 1 standard action  
**Components** V, M (a drop of alcohol)  
**Target** one living creature  
**Duration** 1 day/level  
**Saving Throw** Will negates; **Spell Resistance** yes

This spell functions as *[inveigle person](inveigle-person.md)*, except that it affects any living creature and lasts longer.
