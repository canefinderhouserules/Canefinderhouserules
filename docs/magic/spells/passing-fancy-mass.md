# Passing Fancy, Mass

**School** enchantment (compulsion) [mind-affecting]; **Level** bard 4, mesmerist 4, psychic 5, sorcerer/wizard 5, witch 5  
**Casting Time** 1 standard action  
**Components** V, S  
**Range** close (25 ft. + 5 ft./2 levels)  
**Target** one living creature/level, no two of which can be more than 30 ft. apart  
**Duration** 4d4 rounds (D)  
**Saving Throw** Will negates; **Spell Resistance** yes

This spell functions as *passing fancy*, except as noted above.
