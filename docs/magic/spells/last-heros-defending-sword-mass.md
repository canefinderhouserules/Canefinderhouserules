# Last Hero's Defending Sword, Mass

**School** evocation [force]; **Level** sorcerer/wizard 9  
**Casting Time** 1 standard action  
**Components** V, S, F (a miniature platinum sword worth 250 gp)  
**Effect** up to one sword per 5 levels  
**Duration** 1 round/level (D)  
**Saving Throw** none; **Spell Resistance** yes

This spell functions as *last hero's defending sword*, except you can create one sword per 5 caster levels, each of which must defend a different creature within range.
