# Resistance

**School** abjuration; **Level** bard 0, cleric 0, druid 0, inquisitor 0, medium 0, occultist 0, paladin 1, psychic 0, shaman 0, sorcerer/wizard 0, spiritualist 0, summoner 0, witch 0  
**Casting Time** 1 standard action (1 AP)  
**Components** V, S, M/DF (a miniature cloak)  
**Range** touch  
**Target** creature touched  
**Duration** 1 minute  
**Saving Throw** Will negates (harmless); **Spell Resistance** yes (harmless)

You imbue the subject with magical energy that protects it from harm, granting it a +1 resistance bonus on saves.

*Resistance* can be made permanent with a [*permanency*](permanency.md) spell.
