# Cure Serious Wounds

**School** conjuration (healing); **Level** alchemist 3, bard 3, cleric 3, druid 4, inquisitor 3, occultist 3, paladin 4, ranger 4, shaman 3, spiritualist 3, witch 4  
**Casting Time** 1 standard action (1 AP)  
**Components** V, S  
**Range** touch  
**Target** creature touched  
**Duration** instantaneous  
**Saving Throw** Will half (harmless); **Spell Resistance** yes (harmless); see text

This spell functions like [*cure light wounds*](cure-light-wounds.md), except that it cures 3d8 points of damage + 1 point per caster level (maximum +15).

**Ranged casting**: You can cast this spell as if it were 1 spell level higher (for example, a level 3 spell becomes level 4). If you do, it requires a ranged touch attack instead of a touch, and has a range of close (25 ft. + 5 ft./2 levels). A prepared caster with no way to cast it spontaneously must prepare it this way ahead of time (as if it had a metamagic feat applied, without needing the feat).
