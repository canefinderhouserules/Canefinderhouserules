# Cure Serious Wounds

**School** conjuration (healing); **Level** bard 3, cleric 3, druid 4, paladin 4, ranger 4  
**Casting Time** 1 standard action  
**Components** V, S  
**Range** touch  
**Target** creature touched  
**Duration** instantaneous  
**Saving Throw** Will half (harmless); **Spell Resistance** yes (harmless); see text

This spell functions like *cure light wounds*, except that it cures 3d8 points of damage + 1 point per caster level (maximum +15).
