# Undeath to Death

**School** necromancy; **Level** cleric 6, inquisitor 6, sorcerer/wizard 6, spiritualist 6  
**Casting Time** 1 standard action  
**Components** V, S, M/DF (diamond powder worth 500 gp)  
**Range** medium (100 ft. + 10 ft./level)  
**Area** several undead creatures within a 40-ft.-radius burst  
**Duration** instantaneous  
**Saving Throw** Will negates; **Spell Resistance** yes

This spell functions like [*circle of death*](circle-of-death.md), except that it destroys undead creatures as noted above.
