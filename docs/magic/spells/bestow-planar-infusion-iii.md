# Bestow Planar Infusion III

**School** evocation; **Level** cleric 7, psychic 7, sorcerer/wizard 7, witch 7  
**Casting Time** 1 standard action  
**Components** V, S  
**Range** touch  
**Target** creature touched  
**Duration** 1 hour/level  
**Saving Throw** Fortitude negates (harmless); **Spell Resistance** yes

This functions as [bestow planar infusion I](bestow-planar-infusion-i.md), except that the touched creature gains the greater infusion of the current plane.
