# Charm Monster

**School** enchantment (charm) [mind-affecting]; **Level** bard 3, mesmerist 3, occultist 4, psychic 4, sorcerer/wizard 4, summoner 3, witch 4  
**Casting Time** 1 standard action  
**Components** V, S  
**Target** one living creature  
**Duration** 1 day/level  
**Saving Throw** Will negates; **Spell Resistance** yes

This spell functions like [*charm person*](charm-person.md), except that the effect is not restricted by creature type or size.
