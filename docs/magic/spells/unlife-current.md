# Unlife Current

**School** conjuration (healing) [water]; **Level** antipaladin 3, cleric 3, druid 3, hunter 3, oracle 3, paladin 3, ranger 3, shaman 3, warpriest 3 Casting  
**Casting Time** 1 standard action (1 AP)  
**Components** V, S, DF  
**Range** medium (100 ft. + 10 ft./level)  
**Area** current or portion of current up to 20 feet wide and 100 feet long  
**Duration** 1 round  
**Saving Throw** Will half; **Spell Resistance** yes

This functions as [*life current*](life-current.md) except you infuse the current with negative energy, so it heals undead and harms living creatures.
