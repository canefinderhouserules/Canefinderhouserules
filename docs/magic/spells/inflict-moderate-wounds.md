# Inflict Moderate Wounds

**School** necromancy; **Level** antipaladin 3, cleric 2, inquisitor 2, occultist 2, shaman 2, spiritualist 2, witch 2  
**Casting Time** 1 standard action  
**Components** V, S  
**Range** touch  
**Target** creature touched  
**Duration** instantaneous  
**Saving Throw** Will half; **Spell Resistance** yes

This spell functions like [*inflict light wounds*](inflict-light-wounds.md), except that you deal 2d8 points of damage + 1 point per caster level (maximum +10).

**Ranged casting**: You can cast this spell as if it were 1 spell level higher (for example, a level 2 spell becomes level 3). If you do, it requires a ranged touch attack instead of a touch, and has a range of close (25 ft. + 5 ft./2 levels). A prepared caster with no way to cast it spontaneously must prepare it this way ahead of time (as if it had a metamagic feat applied, without needing the feat).
