# Cure Critical Wounds

**School** conjuration (healing); **Level** alchemist 4, bard 4, cleric 4, druid 5, inquisitor 4, occultist 4, shaman 4, spiritualist 4, witch 5  
**Casting Time** 1 standard action  
**Components** V, S  
**Range** touch  
**Target** creature touched  
**Duration** instantaneous  
**Saving Throw** Will half (harmless); **Spell Resistance** yes (harmless); see text

This spell functions like [*cure light wounds*](cure-light-wounds.md), except that it cures 4d8 points of damage + 1 point per caster level (maximum +20).

**Ranged casting**: You can cast this spell as if it were 1 spell level higher (for example, a level 4 spell becomes level 5). If you do, it requires a ranged touch attack instead of a touch, and has a range of close (25 ft. + 5 ft./2 levels). A prepared caster with no way to cast it spontaneously must prepare it this way ahead of time (as if it had a metamagic feat applied, without needing the feat).
