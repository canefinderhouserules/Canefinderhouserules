# Cure Critical Wounds

**School** conjuration (healing); **Level** bard 4, cleric 4, druid 5  
**Casting Time** 1 standard action  
**Components** V, S  
**Range** touch  
**Target** creature touched  
**Duration** instantaneous  
**Saving Throw** Will half (harmless); **Spell Resistance** yes (harmless); see text

This spell functions like *cure light wounds*, except that it cures 4d8 points of damage + 1 point per caster level (maximum +20).
