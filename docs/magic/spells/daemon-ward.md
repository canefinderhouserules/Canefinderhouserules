# Daemon Ward

**School** necromancy; **Level** cleric 4, druid 5, paladin 4, sorcerer/wizard 4, witch 4  
**Casting Time** 1 standard action  
**Components** V, S, M (50 gp worth of powdered silver)  
**Range** touch  
**Target** living creature touched  
**Duration** 1 min./level  
**Saving Throw** Will negates (harmless); **Spell Resistance** yes (harmless)

This spell functions like [*death ward*](death-ward.md), except as noted above and it only protects against these attacks from daemons.
