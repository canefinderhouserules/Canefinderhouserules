# Hold Fey

**School** enchantment (compulsion) [mind-affecting]; **Level** bard 2, cleric 2, inquisitor 2, sorcerer/wizard 3, witch 2  
**Casting Time** 1 standard action (1 AP)  
**Components** V, S, F/DF (a small, straight piece of iron)  
**Range** medium (100 ft. + 10 ft./level)  
**Target** one fey creature  
**Duration** 1 round/level (D); see text  
**Saving Throw** Will negates; see text; **Spell Resistance** yes

This spell functions as per [*hold person*](hold-person.md), except it affects a fey instead of a humanoid.
