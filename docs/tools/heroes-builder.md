# Heroes Enemy Builder

The [Enemy Builder](enemy-builder.md) for the [Superhero subsystem](../campaign-systems/superheroes/index.md). Pick Warrior, Specialist or Power Master and a level, then choose each class feature from that class's list ([Warrior](../campaign-systems/superheroes/class-features-warrior.md), [Specialist](../campaign-systems/superheroes/class-features-specialist.md), [Power Master](../campaign-systems/superheroes/class-features-power-master.md) and the [generic ones](../campaign-systems/superheroes/generic-class-features.md)): it keeps count of the points of each choice and of the Iconic and OP limits. Stamina and [powers](../campaign-systems/superheroes/spells-and-abilities.md) are built in; a random enemy gets powers on one theme (fire, cold, lightning, mind, force…) from the regular spells, as the subsystem allows. **Copy for Roll20** works as on the monster pages.

The enemy you are making stays in this browser, apart from the ones of the other Enemy Builders. It is the same tool as the [Star Wars Enemy Builder](starwars-builder.md), with this subsystem's names and pages.
