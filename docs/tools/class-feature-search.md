# Class Feature Search

Every class feature that the Build Your Own Class subsystems ([Star Wars](../campaign-systems/star-wars/index.md), [Chakra](../campaign-systems/chakra/chakra-system.md) and [Superheroes](../campaign-systems/superheroes/index.md)) let a class copy, in one list. Each row shows its price and level in the three class types (Warrior, Specialist and the caster type): pick the subsystem to see its names. Tick a class type, price or level band to narrow it, set the highest level you can take, or search by name or by the class it comes from. Click a column name to sort by it; the level links open that list.
