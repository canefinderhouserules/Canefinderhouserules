# Naruto Enemy Builder

The [Enemy Builder](enemy-builder.md) for the [Naruto subsystem](../campaign-systems/chakra/chakra-system.md). Pick Shinobi Warrior, Shinobi Specialist or Jutsu Master and a level, then choose each class feature from that class's list ([Shinobi Warrior](../campaign-systems/chakra/class-features-shinobi-warrior.md), [Shinobi Specialist](../campaign-systems/chakra/class-features-shinobi-specialist.md), [Jutsu Master](../campaign-systems/chakra/class-features-jutsu-master.md) and the [generic ones](../campaign-systems/chakra/generic-class-features.md)): it keeps count of the points of each choice and of the Iconic and OP limits. Chakra and [jutsu](../campaign-systems/chakra/jutsu.md) are built in; a random enemy gets an [element](../campaign-systems/chakra/elements.md) and jutsu of that element (regular spells, as the subsystem allows), plus genjutsu. **Copy for Roll20** works as on the monster pages.

The enemy you are making stays in this browser, apart from the ones of the other Enemy Builders. It is the same tool as the [Star Wars Enemy Builder](starwars-builder.md), with this subsystem's names and pages.
