# Item Search

Every magic item of the wiki in one list, grouped by what it is (armor, weapon, ring, rod, staff, wondrous item by slot...) and not by the book it comes from. Tick types, slots, schools or books to narrow it, set a price range in gp, or leave everything empty to see them all. Click a column name to sort by it.
