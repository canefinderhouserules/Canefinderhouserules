# Lista de class features y sus precios

**OPs:** AC bonus, Flurry, spirit (medium), hexes, spell combat, sneak attack, wildshape, Fervor, sacred weapon, mutagen, Eidolon, challenge, Bardic Performance, Bloodline, Domains, Companion, bane, kinetic blast, cualquier class feature que sea “toma este talento o esta feat cada 2 lvls” vease que no sea solo 1 sino el hecho de conseguir x cada x lvl (rage powers, rogue talents, slayer talents, ki powers, etc).  
  
**Comunes:** favored enemy (según el rol puede volverse OP), smite evil (puede volverse op según el rol), Channel, lay on hands, rage, weapon training, armor training, martial flexibility, Bombs, Discovery, Tactician, Blessings, animal focus, judgements, solo tactics, inspiration, fast movement, Evasion, uncanny dodge, resolve, Shifter claws, familiar/arcane bond, arcane discoveries, Invulnerable Rager’s DR, Phrenic Pool and Amplifications, Hipnotic Stare.

**Debiles:** Poisons, trackless step, wild empathy, woodland stride, Unarmed Strike, favored terrain, trapfinding, trap sense, dual identity, Barbarian’s DR,

**Lista de Feats unicas de este sistema o setting:**

**Extra Class Feature:** Te da una class feature choice extra. Si es del mismo nivel que la feat que estas gastando, no puede ser OP, y solo te da 1 comun o 2 debiles. Si es de 4 niveles menos, puede quizá llegar a ser OP (negociable) y pueden ser 2 comunes o 4 debiles o combinaciones de ambos.  
Se puede tomar multiples veces. NO es una combat feat (así que nada de negrear con la clase full bab).
