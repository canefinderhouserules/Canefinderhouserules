# Gamemastery Guide Random Item Generators

These tables allow the GM to randomly generate specific mundane and magic items, and complement the item generation tables of the Core Rulebook and the [Treasure Generator](index.md). The tables create masterwork versions of armor and weapons; to roll up normal, non-masterwork items, subtract the masterwork cost from the base prices listed. If generated items prove too powerful (or not powerful enough) for your PCs' levels, simply roll again.
