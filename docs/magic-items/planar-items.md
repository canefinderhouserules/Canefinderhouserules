# Planar Items

These magic items help planar travelers survive and thrive in the Great Beyond. If you run a planar adventure, consider placing items from this page before rolling on the random treasure tables. See also [Planar Traits](../rules/campaign/planar-traits.md) and [Planar Infusions](../rules/campaign/planar-infusions.md).

## Armor Special Abilities

| Special Ability | Base Price |
|---|---|
| Billowing | +1 bonus |
| Cocooning | +1 bonus |
| Shadow blending | +2 bonus |
| Cotraveling* | +3 bonus |

\* This special ability can also be applied to shields.

## Weapon Special Abilities

| Special Ability | Base Price |
|---|---|
| Unaligned | +1 bonus |
| Planestriking | +2 bonus |

## Rods

Normal metamagic rods can be used with spells of 6th level or lower. Lesser rods can be used with spells of 3rd level or lower, while greater rods can be used with spells of 9th level or lower.
