# Warrior Class Features

The class features a Warrior can copy, sorted by the level at which the original class gains them and by price. See [Class Features and Their Prices](index.md#class-features-and-their-prices) for how many of each you can take. Prestige class features are listed 3 levels higher than in their class. Features that grant feats are listed once per class, because each class gives a different set of feats. Archetype features show their archetype in parentheses.
