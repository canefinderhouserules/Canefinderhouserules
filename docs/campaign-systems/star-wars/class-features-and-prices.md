# Class Features and Their Prices

**Overpowered (OP):** Flurry, spirit (medium), hexes, spell combat, sneak attack, wildshape, Fervor, mutagen, Eidolon, challenge, Bardic Performance, Bloodline, Domains, Companion, bane, kinetic blast (and elemental focus; see: you choose 1 element), any class feature of the form “take this talent or feat every 2 levels” (note that it is not just 1, but the fact of gaining X every X levels) (Deeds and grit (together), arcane exploits, rogue talents, slayer talents, ki powers, gun masteries, etc).

**Feats and class features unique to this system or setting:**

**Extra Class Feature [Feat]:** Grants one extra class feature choice. If it is of the same level as the feat you are spending, it cannot be OP, and it only gives you 1 common or 2 weak features. If it is 4 levels lower, it can be OP (negotiable), and you can take 2 common or 4 weak features, or a combination of both.  
It can be taken multiple times. It is NOT a combat feat (so no abusing it with a full-BAB class).

**Accelerated Caster [Medium Class Feature]:** Exclusive to the 9th-level-spell class. It gives you an accelerated spell progression similar to a wizard's: essentially you gain 1 spell known of the next spell level one class level earlier, and the rest stays the same (for example, at level 3 you gain 1 known 2nd-level spell, which stays at only 1 at level 4, and at level 5 you gain the second one and the first 3rd-level one).
