# Class Feature Lists

Each Star Wars class can copy class features only from similar classes (see [Classes](index.md#classes)). These lists sort every priced class feature by the kind of class it comes from, with its price. A feature that several kinds of classes have appears in each of their lists. The class names in parentheses are the classes that have the feature; open the link to read it and check its level.
