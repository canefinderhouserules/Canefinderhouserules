# SISTEMA DE ESTAMINA

**Cantidad de Estamina:** numero fijo (según clase) xnivel + atributo de casteol x nivel (como la salud con constitucion, pero con un atributo acorde al poder)

**Los números fijos son:**

**clase 9na esfera:** 12

**clase 6ta esfera:** 8

**clase 4ta esfera:** 6

**Coste de Habilidades:**

**0:** 0-3

**1:** 1-10

**2:** 11-20

**3:** 21-30

**4:** 31-40

**5:** 41-50

**6:** 51-60

**7:** 61-70

**8:** 71-80

**9:** 81-100

**CASTING ABILITY**

El atributo para castear con la fuerza es Wisdom, el atributo para “castear” con tecnologia es Intelligence, si quieren usar algun otro, se puede negociar. Charisma o int para la fuerza no sería del todo imposible, y no se si se les ocurra otra cosa que no sea int para cosas tecnologicas, vemos cualquier cosa.  
Charisma sería mas comun de siths, o de menos esferas, un dominio mas a base de lo fuerte que es tu personalidad, un dominio mas intuitivo, menos tecnico y preciso  
Wisdom es el tipico de la orden jedi  
Inte sería raro entre jedis pero no tanto, sin duda sería mas comun entre siths sorcerers de esos bien turbios alquimistas antiguos

### Class Features

The following are class features of the \[Warrior\] class.

**Weapon and Armor Proficiency**

A \[Warrior\] is proficient in \[all simple and martial weapon types and 1 exotic weapon\] and \[all armor types\].

**Warrior Class Feature (Ex, Sp, Su)**

A nivel 1, 2 y cada 2 niveles consiguen una class feature a su eleccion, desde custom para representar algo muy único y diferente a sistematizar y balancear (torturar) con el gm de turno (o sea yo, el único autista de balance) hasta robada de clases de pathfinder.  
  
Esto es completamente experimental, pero por ahora las únicas minusculas reglas que se me cruzaron por la cabeza para mantener cierto grado de sentido son:  
- Podes copiar cualquier class feature del mismo nivel que conseguis la class feature o menos (no podes copiar la class feature Bane con una class feature lvl 2, ya que es una class feature lvl 5 en la clase de inquisitor).

\- Podes copiar class features solo de clases similares. Marcial de marciales (y de marciales hibridos negociable quizá de menor nivel). En el caso del Shinobi Warrior, solo puede copiar de clases sin spells, o con spells de 4ta, y posiblemente con spells de 6ta con posible leveo mas debil o que gaste una class feature de nivel mas alto.

\- Cada class feature tiene un valor diferente, dividido entre OP, comun, y Debil. Cada vez que elegis una class feature podes elegir 1 OP, o 2 comunes, o 4 debiles (o 1 comun y 2 debiles). **MÁXIMO 4 CLASS FEATURES OPS.** Negociable.

**Powerless (Ex, Sp, Su)**

Class feature opcional que representa personajes que no tienen poderes o aptitudes tecnologicas locardas, o personajes que solo quieren tener la cosa mas brainded basica pasiva y no pensar en nada mas. En vez de spells, reciben algo pasivo permanente a discutir con el master de turno, similar a un spell de lvl 1 permanente a nivel 1, que mejora a nivel 2 a nivel 4, a nivel 3 al 7, 4 al 10 y 5 al 13.

**Mutation (Ex, Sp, Su)**

Mas que una class feature, un delimitante del tipo de poderes y habilidaades que podes desarrollar con el personaje, algo mas narrativo que otra cosa, pero obviamente según lo que elijan puede ser algo mas copado e interesante, quizá hasta op por variedad. Quizá le ponga precio o vuelva mas op algo de alguna forma a mas limitante sea (o precio en exp a mas abarcativo sea).

Esto obviamente se decide a lvl 1 y el master debe saberlo.

### Class Features

The following are class features of the \[class\] \[prestige\] class.

**Weapon and Armor Proficiency**

A \[Consular\] is proficient in \[Simple Weapons\] and \[Lightsabers\].

**Force Sensitive (Su)**

Ganas la feat de Force Sensitive ta mas abajo.

**Consular Class Feature (Ex, Sp, Su)**

A nivel 1, 2 y cada 2 niveles consiguen una class feature a su eleccion, desde custom para representar algo muy único y diferente a sistematizar y balancear (torturar) con el gm de turno (o sea yo, el único autista de balance) hasta robada de clases de pathfinder.  
  
Esto es completamente experimental, pero por ahora la única minuscula regla que se me cruzo por la cabeza para mantener cierto grado de sentido es:  
- Podes copiar cualquier class feature del mismo nivel que conseguis la class feature o menos (no podes copiar la class feature Bane con una class feature lvl 2, ya que es una class feature lvl 5 en la clase de inquisitor).

\- Podes copiar class features solo de clases similares. Marcial de marciales (y de marciales hibridos negociable quizá de menor nivel). En el caso del Warrior, solo puede copiar de clases sin spells, o con spells de 4ta, y posiblemente con spells de 6ta con posible leveo mas debil o que gaste una class feature de nivel mas alto.

\- Cada class feature tiene un valor diferente, dividido entre OP, comun, y Debil. Cada vez que elegis una class feature podes elegir 1 OP, o 2 comunes, o 4 debiles (o 1 comun y 2 debiles). Probablemente límite a solo 2 OPs o quizá prohiba algunas mezclas. Todo negociable.
