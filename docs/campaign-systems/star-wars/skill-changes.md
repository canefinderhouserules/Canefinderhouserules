# Skill Changes

- **Arcana** becomes **Science**.
- **Planes** is either ignored, or used for computer science knowledge.
- **Engineering** becomes engineering, but with robots.
- You can always ignore these and add new ones, since it costs little. This is mostly so that traits and other things that applied to the old skills now work for these; otherwise we will sort it out as we go.
- **Disable Device** is slicing.
- **Navigation** should be added, because technically Ride still works. It would be Intelligence-based, but could also use Dexterity, or Wisdom if force flying comes up.
