# Specialist Class Features

The class features a Specialist can copy, sorted by the level at which the original class gains them and by price. See [Class Features and Their Prices](index.md#class-features-and-their-prices) for how many of each you can take. Prestige class features are listed 3 levels higher than in their class. Features that grant feats are listed once per class, because each class gives a different set of feats. Archetype features show their archetype in parentheses. Features that many classes repeat are unified in [Generic Class Features](generic-class-features.md), where you choose what they apply to. To search every class feature at once, with each one's place in all three lists, use the [Class Feature Search](../../tools/class-feature-search.md).
