# Jutsu Master Class Features

The class features a Jutsu Master can copy, sorted by the level at which the original class gains them and by price. See [Class Features and Their Prices](class-features-and-prices.md#class-features-and-their-prices) for how many of each you can take. Prestige class features are listed 3 levels higher than in their class. Features that grant feats are listed once per class, because each class gives a different set of feats. Archetype features show their archetype in parentheses. Features that many classes repeat are unified in [Generic Class Features](generic-class-features.md), where you choose what they apply to. To search every class feature at once, with each one's place in all three lists, use the [Class Feature Search](../../tools/class-feature-search.md).

Classes with a 1/2 base attack bonus or 9th-level spells. Prestige classes count here only with a 1/2 base attack bonus. Classes: Adventuring Savant, Agent of the Grave, Arcane Trickster, Arcanist, Arclord of the Eye, Argent Dramaturge, Balanced Scale, Blood Bloatmage, Cleric, Cyphermage, Daivrat, Darkfire Adept, Desert Alchemist, Diabolist, Druid, Enchanting Courtesan, Envoy of Balance, Fate Reader, First Magic Arcanist, Genie Binder, Legendary Cleric, Loremaster, Mystic Theurge, Oracle, Prophet of Commerce, Psychic, Ritualist, Runeguard, Scarlet Assassin, Shaman, Sigil Mystic, Sorcerer, Technomancer, Veiled Illusionist, Winter Witch, Witch, Wizard.
