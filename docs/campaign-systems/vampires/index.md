# Vampire Subsystem

!!! note "Custom subsystem"
    This is a free, fan-made campaign subsystem created for our table. It is completely separate from the normal Pathfinder rules and is not copied from any official system. It is written for the players to read.

- [Effects of Being a Vampire](vampire-traits.md): racial traits, frenzy, blood pool, generation and discipline costs.
- [Clans](clans.md): curses and disciplines of each clan.
- [Disciplines](disciplines.md): common powers and each discipline's levels.
- [Casters](casters.md): how vampires use magic classes.
- [New Feats](new-feats.md)
- [Humanity](humanity.md): the Path of Humanity and its effects.
- [Mythic Path Abilities](mythic-path-abilities.md): how mythic points work in this game, and the ability list.
