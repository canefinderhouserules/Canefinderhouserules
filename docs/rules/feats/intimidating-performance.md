# Intimidating Performance

Your performance strikes fear in the hearts of foes.

**Prerequisites**: Ability to start a performance (or raging song) as a move action (1 AP), bardic performance or raging songt class feature.

**Benefit**: When you start a performance (or a raging song) as a move or swift action (1 AP), you can use a standard action (1 AP) to demoralize a foe (Core Rulebook 99), attempting a [Perform](../skills/perform.md) check appropriate to your performance in place of the [Intimidate](../skills/intimidate.md) check. Your performance must be one with an audible component. If you can start a performance as a swift action (1 AP) and you have the [Dazzling Display](dazzling-display.md) feat, you can gain the benefit of Dazzling Display by succeeding at a Perform check in place of an Intimidate check.
