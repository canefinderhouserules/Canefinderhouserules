# Mutated Shape

Your wild shape form gains an additional appendage you can use to attack your foes.

**Prerequisites**: Wis 19, base attack bonus +6, wild shape class feature.

**Benefit**: When you use wild shape, you grow an additional appendage of your choice that can be used to make one of the following attacks: bite, claw, gore, slam, sting, or talons. The appendage can be used as part of a full attack using your highest base attack bonus, and it deals damage as described in lasts for as long as you stay in the same form with this use of wild shape.
