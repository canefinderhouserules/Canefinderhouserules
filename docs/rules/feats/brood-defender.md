# Brood Defender

When someone under your protection is set upon, you react viciously against the attacker.

**Prerequisites**: [Bodyguard](bodyguard.md), [Combat Reflexes](combat-reflexes.md), wyvaran.

**Benefit**: If an opponent misses its attack on an ally after you successfully used the aid another action to improve that ally's AC this round, you can attempt an [Intimidate](../skills/intimidate.md) check as an immediate action to demoralize that opponent.
