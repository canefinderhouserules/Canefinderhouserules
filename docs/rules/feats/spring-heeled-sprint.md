# Spring-Heeled Sprint

*(Combat)*

You can move quickly without sacrificing your offense.

**Prerequisites**: Dex 15, Dodge, [Mobility](mobility.md), Shot on the Run or Spring Attack, [Spring-Heeled Style](spring-heeled-style.md), base attack bonus +7, proficiency with light armor.

**Benefit**: While using Spring-Heeled Style, you can move up to twice your speed when using the Shot on the Run or Spring Attack feats.
