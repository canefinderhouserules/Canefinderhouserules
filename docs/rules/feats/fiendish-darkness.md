# Fiendish Darkness

You can use your [*darkness*](../../magic/spells/darkness.md) spell-like ability more often.

**Prerequisites**: [*Darkness*](../../magic/spells/darkness.md) spell-like ability, tiefling.

**Benefit**: You can use [*darkness*](../../magic/spells/darkness.md) three times per day as a spell-like ability.

**Normal**: Tieflings can use [*darkness*](../../magic/spells/darkness.md) once per day as a spell-like ability.
