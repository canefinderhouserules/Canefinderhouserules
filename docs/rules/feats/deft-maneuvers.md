# Deft Maneuvers

*(Combat)*

**Prerequisite**: Int 10.

**Benefit**: You do not provoke an attack of opportunity when performing a trip, disarm, dirty trick, feint, reposition, or steal combat maneuver. In addition, you receive a +2 bonus on checks with these combat maneuvers.

**Special**: This feat is a prerequisite for the relevant greater combat maneuver feats.

**Note**: This feat combines [Improved Trip](improved-trip.md), [Improved Disarm](improved-disarm.md), [Improved Feint](improved-feint.md), [Improved Dirty Trick](improved-dirty-trick.md), [Improved Reposition](improved-reposition.md), [Improved Steal](improved-steal.md), which remain available on their own.
