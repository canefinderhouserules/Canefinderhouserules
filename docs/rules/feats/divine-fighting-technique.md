# Divine Fighting Technique

*(Combat)*

You have trained in the fighting technique of a deity.

**Prerequisites**: Same alignment as the chosen technique’s patron.

**Benefit**: Select a [divine fighting technique](../combat/divine-fighting-techniques.md). You can use that technique and receive any benefit for which you qualify.

**Special**: You can gain this feat multiple times. Each time you take this feat, it applies to a new divine fighting technique.
