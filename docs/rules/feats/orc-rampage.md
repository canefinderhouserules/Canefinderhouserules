# Orc Rampage

*(Combat)*

You effortlessly savage fearful enemies.

**Prerequisites**: [Bullying Blow](bullying-blow.md), [Intimidating Prowess](intimidating-prowess.md), [Orc Fury Style](orc-fury-style.md), Intimidate 5 ranks, weapon familiarity racial trait.

**Benefit**: While using [Orc Fury Style](orc-fury-style.md), you gain a +1 bonus on attack rolls and damage rolls against [shaken](../appendices/conditions.md#shaken) opponents, and you don’t take an attack penalty when using the [Bullying Blow](bullying-blow.md) feat.
