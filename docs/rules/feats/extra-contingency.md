# Extra Contingency

You can manage multiple [*contingency*](../../magic/spells/contingency.md) effects.

**Prerequisite**: Character level 19th.

**Benefit**: You can have two [*contingency*](../../magic/spells/contingency.md) effects active at one time. If they would both trigger on the same round, one (chosen randomly) does not trigger until 1 round later.

**Normal**: You can benefit from only a single [*contingency*](../../magic/spells/contingency.md) active at a time.
