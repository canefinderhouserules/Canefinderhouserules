# Improved Hammer Throw

*(Combat)*

Your ability to knock down your foes with ranged attacks is impressive.

**Prerequisites**: [Hammer Throw](hammer-throw.md), [Improved Trip](improved-trip.md), [Point-Blank Shot](point-blank-shot.md), [Precise Shot](precise-shot.md), base attack bonus +6, dwarf.

**Benefit**: You can use the [Hammer Throw](hammer-throw.md) feat against targets at any range and of any size.

??? note "Original prerequisites"

    **Prerequisites**: Int 13, Combat Expertise, Hammer Throw, Improved Trip, Point-Blank Shot, Precise Shot, base attack bonus +6, dwarf.
