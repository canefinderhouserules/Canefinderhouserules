# Greater Tenacious Hunter

The animal is capable of savaging hidden foes when they least expect it.

**Prerequisites**: [Combat Reflexes](combat-reflexes.md), [Tenacious Hunter](tenacious-hunter.md), Perception 3 ranks, Stealth 3 ranks, animal companion.

**Benefit**: The animal companion can attempt a [Perception](../skills/perception.md) check as a swift action (1 AP) to intentionally search for a stimulus. When using Perception to attempt to pinpoint an invisible foe, the animal companion’s bonus from the [Tenacious Hunter](tenacious-hunter.md) feat increases to +20. In addition, whenever the animal companion successfully uses Perception to oppose a [Stealth](../skills/stealth.md) check or to pinpoint an invisible creature’s location, that foe is denied its Dexterity bonus to AC against all attacks that the animal companion makes before the start of the animal companion’s next turn.

**Normal**: Using Perception to intentionally search for a stimulus is a move action (1 AP).
