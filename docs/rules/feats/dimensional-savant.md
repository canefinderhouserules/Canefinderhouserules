# Dimensional Savant

You f lash into and out of reality so quickly it is impossible to tell exactly where you are at any given time.

**Prerequisites**: Dimensional Agility, Dimensional Assault, Dimensional Dervish, ability to use the abundant step class feature or cast dimension door, base attack bonus +9.

**Benefit**: While using the Dimensional Dervish feat, you provide f lanking from all squares you attack from. Flanking starts from the moment you make an attack until the start of your next turn. You can effectively f lank with yourself and with multiple allies when using this feat.
