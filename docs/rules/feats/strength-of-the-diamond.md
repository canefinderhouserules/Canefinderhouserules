# Strength of the Diamond

Your extensive training with fellow regiment soldiers has bolstered you against fear.

**Prerequisites**: Con 13, Wis 13, character level 3rd, member of an elite regiment.

**Benefit**: Any effect that would normally make you [panicked](../appendices/conditions.md#panicked) instead makes you [frightened](../appendices/conditions.md#frightened). Any effect that would make you frightened instead makes you [shaken](../appendices/conditions.md#shaken). Any effect that would make you shaken has no effect on you. Note that you can still become increasingly frightened by multiple fear effects from different sources, but that each source is modified before it is applied to you. In addition, you gain a +2 bonus on any saving throw versus fear effects.
