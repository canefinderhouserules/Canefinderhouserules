# Perfect Awareness

*(Combat)*

You can set aside all irrelevant sensory information to understand your surroundings perfectly for a moment.

**Prerequisites**: Wis 17, [Combat Meditation](combat-meditation.md), [Meditation Master](meditation-master.md), character level 9th.

**Benefit**: Once per day, you can take 20 on a [Perception](../skills/perception.md) check as a move action (1 AP).
