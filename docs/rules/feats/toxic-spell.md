# Toxic Spell

*(Metamagic)*

**Benefit**: You can use 1 dose of contact, ingested, inhaled, or injury poison as an additional material component for a spell you cast. This spell gains the poison descriptor. Select a single creature affected by the spell. If that creature fails its saving throw against the spell, it must also attempt a saving throw against the poison used as a material component. If the target fails the save against the poison, the poison takes effect immediately, ignoring any onset time. The poison uses the spell save DC. This feat works only with spells whose effects can be negated by a successful Fortitude save.

**Level Increase**: +1

**Category**: Trait
