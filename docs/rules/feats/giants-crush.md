# Giant’s Crush

*(Combat)*

When you strike hard, you knock smaller foes off their feet.

**Prerequisites**: Str 13, [Power Attack](power-attack.md), [Vital Strike](vital-strike.md), base attack bonus +6, giant subtype.

**Benefit**:  If you hit a creature at least one size category smaller than you with a melee attack while using both [Power Attack](power-attack.md) and [Vital Strike](vital-strike.md), the creature that you attacked is also knocked prone. A successful Reflex save negates this effect (DC = 10 + your base attack bonus). You must choose to use this feat before making the attack roll.

**Special**:  This effect stacks with the effect of [Giant’s Wallop](giants-wallop.md).
