# Duelist Style

*(Combat, Style)*

You have learned the classic dueling stance.

**Prerequisites**: [Alertness](alertness.md), Exotic Weapon Proficiency (dueling sword), [Weapon Finesse](weapon-finesse.md), Weapon Focus (dueling sword).

**Benefit**: While using Duelist Style and wielding only a single dueling sword in one hand (not using a shield, an off-hand weapon, armor spikes, unarmed strikes, or natural weapons), when you fight defensively or use [Combat Expertise](combat-expertise.md), you gain a +2 bonus on weapon damage rolls.
