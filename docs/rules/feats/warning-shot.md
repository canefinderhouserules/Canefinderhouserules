# Warning Shot

*(Combat)*

An intentional near-miss demonstrates your frightening skill at range.

**Prerequisites**: [Point-Blank Shot](point-blank-shot.md), [Precise Shot](precise-shot.md), [Weapon Focus](weapon-focus.md), proficiency with the selected weapon.

**Benefit**: As a standard action (1 AP), you can make a ranged touch attack using a ranged weapon with which you have Weapon Focus. If successful, instead of dealing damage or applying any other effects of the attack, you may attempt an [Intimidate](../skills/intimidate.md) check to demoralize the target as a free action. The target doesn't need to be within 30 feet, nor does it need to be able to see or hear you.
