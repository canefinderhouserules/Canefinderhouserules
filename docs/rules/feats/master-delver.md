# Master Delver

You’ve spent some time in the sunken ruins beneath a great port and have learned a little bit to help you survive.

**Prerequisites**: Explored part of a sunken ruin.

**Benefit**: You get a +2 bonus on all [Knowledge](../skills/knowledge.md) (dungeoneering) checks and [Perception](../skills/perception.md) checks made to notice traps. Knowledge (dungeoneering) is always a class skill for you.
