# Twin Fang Lunge

*(Combat)*

You strike with the force of a serpent's lunge.

**Prerequisites**: Dex 15, [Quick Draw](quick-draw.md), [Twin Fang Strike](twin-fang-strike.md), [Twin Fang Style](twin-fang-style.md), [Two-Weapon Fighting](two-weapon-fighting.md), Acrobatics 8 ranks, base attack bonus +8 or monk level 8th.

**Benefit**: While using [Twin Fang Style](twin-fang-style.md), you can spend a full-round action to move up to twice your speed and then use [Twin Fang Strike](twin-fang-strike.md) as if you were taking the attack action.
