# Janni Style

*(Combat, Style)*

Your whirling fighting technique makes you difficult to hit.

**Prerequisites**: Improved Unarmed Strike, Acrobatics 3 ranks, Perform (dance) 3 ranks.

**Benefit**: While using this style, you take only a –1 penalty to AC for charging. Further, opponents that f lank you gain only a +1 bonus on attack rolls against you.
