# Slow Time

*(Combat)*

Meditation allows you to perceive time as if it were moving more slowly.

**Prerequisites**: Wis 15, [Combat Meditation](combat-meditation.md), [Meditation Master](meditation-master.md), character level 7th.

**Benefit**: Once per day, when you meditate as a full-round action using the [Combat Meditation](combat-meditation.md) feat, you gain the effects of [*haste*](../../magic/spells/haste.md) for 1 round per 2 character levels. These effects do not stack with the *haste* spell, the *speed* magic weapon special ability, or other effects granting the same result. This is an extraordinary ability.
