# Boar Shred

*(Combat)*

The wounds you inflict with your unarmed strikes bleed, giving you renewed vigor.

**Prerequisites**: [Improved Unarmed Strike](improved-unarmed-strike.md), [Boar Ferocity](boar-ferocity.md), [Boar Style](boar-style.md), Intimidate 9 ranks.

**Benefit**: You can make an [Intimidate](../skills/intimidate.md) check to demoralize an opponent as a move action. While using [Boar Style](boar-style.md), whenever you tear an opponent’s flesh, once per round at the start of that opponent’s turn he takes 1d6 bleed damage. The bleed damage dealt while using Boar Style persist even if you later switch to a different style.
