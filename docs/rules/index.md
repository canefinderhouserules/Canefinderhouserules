# Rules

The rules of the game as we play them. Anywhere a rule differs from the book, the page starts with an orange **House rule** box.

- **Getting Started:** ability scores, common terms, generating a character.
- **Combat:** how combat works, actions, special attacks, injury and death, combat styles and tricks.
- **Skills:** every skill, with the extra uses and options added by later books.
- **Feats:** the complete feat list, with prerequisites.
- **Variant and optional rules:** variant combat, additional rules, unchained, occult, horror, mythic, wilderness, technology, vehicles and the race builder.
- **Campaign Rules:** downtime, intrigue, kingdoms and war, leadership and cohorts, contacts and campaign systems.
- **Appendices:** conditions, special abilities, diseases, poisons, curses and afflictions.

!!! info "Work in progress"
    A few core pages may list only the changes from the original text. If a rule seems to be missing, use the search box before assuming it is absent.
