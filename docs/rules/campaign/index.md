# Campaign Rules

!!! note "Source"
    Rules from *Pathfinder Roleplaying Game: Ultimate Campaign*.

This section collects the rules that help the GM and players build the story around the adventure: [character backgrounds](character-background.md) and the [background generator](background-generator.md), plus the [traits](../../characters/traits/additional-traits.md), [drawbacks](../../characters/traits/drawbacks.md) and [story feats](../feats/story-feats.md) that tie a character to the campaign.

The [downtime rules](downtime/index.md) cover capital, downtime activities, managers, and building rooms, teams, buildings, organizations, and the random events that affect them.

The [campaign systems](campaign-systems/index.md) are optional modules for alignment, bargaining, companions, contacts, exploration, honor, investment, lineage, magic item creation, relationships, reputation, retirement, retraining, taxation, and young characters.
