# General Rules

**- Coup de grace** ya no tiene save de muerte, vease ya no mata.

**- Shoot into Melee:** El penalizador de -4 de disparar a alguien luchando a melee ahora es -2.

**- Intimidate:** podes sumar fuerza o carisma.

**- Natural Attacks/Attacks:**

-- Limites: El mismo limite que los eidolons aplica a los jugadores, vease un limite de ataques basado en el nivel del personaje.

-- Single Attack: Para formas o animales que tengan 1 unico ataque para siempre, pueden gastar 1 feat para ganar itteratives (como la class feature del Shifter) es decir ataques cada 5 bab con -5 ataque, lo tipico.

**- Daño por dado de sorcerer/blood havoc/orc/draconic/flumefire:** ya no es "untyped stackea". vease solo podes tener 1, 2 si vas flumefire con rage, se toma el mas alto, reglas de siempre.

**- Channel Energy:** no es necesario elegir entre curar o dañar, solo entre positivo o negativo, lo que sea que hagas, lo causa a todos en el area debida (curando gente viva, dañando gente muerta en caso de positivo, lo contrario para negativo) ademas sube a 1d8.

**Favored Class Bonus, Prestige Class:** Podes elegir una prestige class como tu favored class si así lo queres, no tenes ambas, no tenes nada especial, solo laa elegis en vez de una clase normal, nada fuera de lo habitual. Para toda otra cosa se requieren las feats y etc.

**Extra regla opcional de Run Action:** Cada Run Action requiere una tirada de fort save, de DC 10. La DC aumenta en +5 cada run action consecutiva. Fallar te provoca Fatigue durante 1 minuto.

**Prone:** El +4ca vs rango no aplica contra ataques de rango que provengan de alguien adjacente con armas que disparen instantaneamente, contando incluso el negativo a melee. Sigue provocando AoO aunque el proneado tendría -4 ataque como siempre.
