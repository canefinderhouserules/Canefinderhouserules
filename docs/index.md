# Canefinder

Pathfinder 1e as we play it at our table.

Use the tabs at the top (or the search box) to find what you need. Whenever a rule differs from the book, the page starts with an orange **House rule** box.

- **Rules:** combat, skills and general changes.
- **Characters:** character options, classes, favored class bonuses.
- **Magic:** domains.
- **Equipment:** weapons and special weapon properties.
- **Campaign Systems:** Star Wars, chakra, vampires and other systems used in some campaigns.
