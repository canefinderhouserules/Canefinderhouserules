# Prestige Class as Favored Class

!!! warning "House rule"
    A prestige class can be your favored class.

You may choose a **prestige class** as your favored class instead of a base class.

- You still have **only one** favored class. You cannot have both a base and a prestige favored class.
- This gives no special benefit beyond that. Any other requirement (feats and so on) works as normal.
