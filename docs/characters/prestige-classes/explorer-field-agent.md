# Explorer Field Agent

Equipped with a variety of skills and trained to keep a cool head even in the most dire circumstances, a practiced explorer field agent is a boon to any adventuring party.

**Hit Dice**: d8.

### Requirements

To qualify to become an explorer field agent, a character must fulfill all the following criteria.

**Feats**: Skill Focus (any).

**Skills**: Knowledge (any) 5 ranks, Linguistics 1 rank, Perception 1 rank.

**Special**: Must be an active member of an explorers’ society and own a *wayfinder*.

### Class Skills

The explorer field agent’s class skills are Bluff (Cha), Climb (Str), Diplomacy (Cha), Disable Device (Dex), Escape Artist (Dex), Heal (Wis), Knowledge (all) (Int), Linguistics (Int), Perception (Wis), Sense Motive (Wis), Stealth (Dex), Swim (Str), and Use Magic Device (Cha).

**Skill Ranks Per Level**: 6 + Int modifier.

### Class Features

The following are class features of the explorer field agent prestige class.

**Weapon and Armor Proficiency**: An explorer field agent gains no additional weapon or armor proficiencies.

**Field Training**: An explorer field agent receives additional training that aids her in her fulfilling her duty to explore, report, and cooperate. She can’t receive the same training more than once unless otherwise noted. An explorer field agent gains additional field training at 3rd level and every 3 levels thereafter.

*Animal Magnetism (Ex)*: This ability functions as the druid’s wild empathy class ability, except the explorer field agent’s effective druid level to determine her wild empathy bonus is equal to her explorer field agent level. Levels in explorer field agent stack with levels from other classes that grant wild empathy for the purpose of determining an explorer field agent’s total wild empathy bonus.

*Deft Defender (Ex)*: When the explorer field agent successfully uses the aid another action to increase an ally’s Armor Class, she gains a +1 dodge bonus to her AC until the start of her next turn.

*Eidetic Memory (Ex)*: Years of training in the libraries of countless explorers’ lodges have given the explorer field agent extraordinary recall. An explorer field agent with this training adds half her class level (minimum 1) to all Knowledge skill checks and can attempt all Knowledge skill checks untrained.

*Greater Casting*: The explorer field agent gains new spells per day as if she had also gained a level in a spellcasting class she belonged to before adding the prestige class. She doesn’t gain other benefits of that class other than spells per day, spells known, and an increased caster level. If the explorer field agent has levels in more than one spellcasting class, she must choose which class to apply this increase to when she takes this field training.

*Know Thy Enemy (Ex)*: The explorer field agent can select one creature type, and gains a +5 bonus on Knowledge checks to identify creatures of the chosen type. This can be taken more than once, and applies to a different creature type each time.

*Rogue Talent*: The explorer field agent can select any rogue talent for which she qualifies.

*Skill Specialization (Ex)*: The explorer field agent can select any skill to become a class skill for her. In addition, she gains a bonus on checks with the chosen skill equal to half her class level. This training can be selected more than once, applying to a different skill each time it is taken.

*Sneak Attack +1d6 (Ex)*: This ability is exactly like the rogue ability of the same name. If the explorer field agent gains a sneak attack bonus from another source, the bonuses on damage stack. An explorer field agent must be at least 3rd level before selecting this training.

*Trapfinding*: This training functions as the rogue class feature of the same name. Levels in explorer field agent stack with levels from other classes that grant this ability for the purpose of determining an explorer field agent’s total trapfinding bonus.

**Wayfinder Upgrade**: At 1st level and every 3 levels thereafter, an explorer field agent can add an additional ability to her *wayfinder*. These abilities must be added to a standard *wayfinder *(see *explorer Campaign Setting: The Inner Sea World Guide* 299), not to a variant or modified *wayfinder *(though an explorer field agent can possess more than one *wayfinder* at a time, if she chooses). If an explorer field agent loses her upgraded *wayfinder*, she can purchase a new one at the normal cost plus 100 gp for each explorer field agent level she possesses, keeping all previously selected upgrades. An explorer field agent can choose from the listed *wayfinder* upgrades. Any upgrades that grant additional spell effects use the *wayfinder’s* caster level or the explorer field agent’s class level (whichever is higher) to determine effects that depend on caster level.

*Dancing Lights*: The explorer field agent replaces her *wayfinder’s* ability to cast *light* with the ability to cast *dancing lights* at will.

*Daylight*: Once per day, the explorer field agent can use her *wayfinder* to cast *daylight*. This upgrade can be selected more than once. Each additional time it’s selected, the explorer field agent gains another use of the spell per day.

*Flask*: A hidden compartment is carved into the *wayfinder’s* casing, allowing a single potion, oil, or dose of poison to be hidden within. This substance can be retrieved with a swift action that doesn’t provoke attacks of opportunity (as opposed to the normal move action required to retrieve a stored item). Drinking the potion or applying the oil or poison still requires a standard action that provokes attacks of opportunity. The explorer field agent gains a +2 bonus on Sleight of Hand checks made to oppose the Perception check of someone observing or frisking her to detect items in the hidden compartment.

*Hidden*: In order to hide her affiliation with an explorers’ society from potential enemies, an explorer field agent with this upgrade can, three times per day, turn her *wayfinder* invisible and mask its magical aura as if it were under the effects of *invisibility* and *magic aura*. Each time this effect is used, it lasts for up to 1 hour per 2 class levels the explorer field agent possesses (minimum 1 hour), and can be dismissed by the explorer field agent as a move action.

*Message*: In addition to the *light* spell-like ability, the *wayfinder* can be used to cast *message* at will.

*Shielding*: Once per day, the explorer field agent can activate her *wayfinder* to gain a +2 deflection bonus to AC for a number of minutes equal to her explorer field agent level. This bonus increases by 1 for every 5 class levels the explorer field agent possesses.

*Silence*: Once per day, the explorer field agent can use her *wayfinder* to emit an aura of *silence*, as the spell. The *silence* effect must be centered on the *wayfinder*. This upgrade can be selected more than once. Each additional time the upgrade is selected, the agent gains another use of the spell per day.

*Stabilize*: The wayfinder can be used to cast *stabilize* at will.

**Bonus Feat**: At 2nd level and every 3 levels thereafter, an explorer field agent can select a bonus feat. Each of these bonus feats must be Skill Focus or a teamwork feat. The explorer field agent must meet the prerequisites of the selected bonus feat.

**Legends Uncovered (Su)**: At 10th level, an explorer field agent has the ability to uncover the secrets of the distant past. Once per day when studying or researching a person, place, or artifact of antiquity, the agent can dedicate herself to the task to gain benefits as though she were casting the spell *legend lore*.
